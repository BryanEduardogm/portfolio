NovaCell

Loja de celulares

  • HTML
  • CSS
  • JavaScript
  • localStorage

Uma loja de eletrônicos de oito páginas, com catálogo de 160 produtos. É o projeto mais completo em quantidade de tela: o cliente busca, filtra, monta o carrinho, calcula o frete e fecha o pedido.

  • Busca e filtros por categoria, preço e destaque
  • Carrinho que continua cheio depois de fechar o navegador
  • Calculadora de frete e simulador de troca do aparelho usado
  • Login, área de perfil e finalização de compra

AutoForte Motors

Concessionária

  • HTML
  • CSS
  • JavaScript
  • Node.js
  • Express
  • MongoDB

Uma landing page de página única, pensada para levar o visitante do primeiro olhar até o agendamento de um test-drive sem nunca sair da tela.

  • Rolagem única com navegação por âncoras
  • Vitrine de estoque, seção da equipe e depoimentos de clientes
  • Formulário de contato e test-drive com validação campo a campo
  • Servidor em Node.js que recebe e guarda os pedidos

MóveisHouse

Loja de móveis

  • HTML
  • CSS
  • JavaScript
  • Node.js
  • Express
  • MongoDB

Um e-commerce de móveis que cabe numa página só. O catálogo, o carrinho e o checkout convivem na mesma tela, sem recarregar nada.

  • Carrinho e lista de desejos que sobrevivem ao fechar a aba
