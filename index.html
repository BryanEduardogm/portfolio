NovaCell

Loja de celulares

  • HTML
  • CSS
  • JavaScript
  • localStorage

Uma loja de eletrônicos de oito páginas, com catálogo de 160 produtos. É o projeto mais completo em quantidade de tela: o cliente busca, filtra, monta o carrinho, calcula o frete e fecha o pedido.

  • Busca e filtros por categoria, preço e destaque
  • Carrinho que continua cheio depois de fechar o navegador
  • Calculadora de frete e simulador de troca do aparelho usado
  • Login, área de perfil e finalização de compra

MóveisHouse

Loja de móveis

  • HTML
  • CSS
  • JavaScript
  • Node.js
  • Express
  • MongoDB

Um e-commerce de móveis que cabe numa página só. O catálogo, o carrinho e o checkout convivem na mesma tela, sem recarregar nada.

  • Catálogo com filtros por ambiente e faixa de preço
  • Carrinho e lista de desejos que sobrevivem ao fechar a aba
  • Área de login e tela de pagamento
  • Formulário de orçamento para projetos sob medida

Pata Amiga

Clínica veterinária

  • HTML
  • CSS
  • JavaScript
  • Node.js
  • Express
  • bcrypt

O único da lista que vende serviço, não produto — e por isso o desafio mudou: em vez de carrinho, uma agenda. Em vez de vitrine, confiança.

  • Agendamento de consulta com escolha de serviço, data e horário
  • Cadastro e login com senha criptografada
  • Área do tutor com os agendamentos marcados
  • Páginas de serviços, equipe e depoimentos

APEX

Coleção de carros

  • HTML
  • CSS
  • JavaScript
  • Three.js
  • WebGL

Catorze carros, cada um com página própria. O modelo 3D não é um arquivo baixado: é montado por código a partir das medidas e do estilo de carroceria de cada carro.

  • Carro em 3D gerado por parâmetros — proporções, carroceria, aerofólio e cor da pintura
  • Gira ao arrastar, direto no navegador, sem plugin
  • Ficha técnica montada a partir de uma fonte única de dados
  • Coleção com filtro e página de detalhe para cada modelo

VoltBet

Apostas e cassino

  • HTML
  • CSS
  • JavaScript
  • localStorage

Site de apostas esportivas feito como demonstração: o saldo é fictício e fica só no navegador. Sete jogos de cassino escritos do zero, sem biblioteca de jogos.

  • Cupom de apostas que soma as seleções e calcula o retorno
  • Aviator, Mines, Plinko, Roleta e três slots, cada um em seu arquivo
  • Saldo, extrato e recarga guardados entre visitas
  • Jogo responsável: aviso +18, teto mensal de depósito e opção de zerar a conta
